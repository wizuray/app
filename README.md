# Wizuray

Private messages and calls, straight from device to device.
No accounts, no phone numbers.

## Download

The apps for Android and Windows are on the
[Releases](https://github.com/wizuray/app/releases) page.
The source code is not public.

## Problems and ideas

- Found a problem? Open an [issue](https://github.com/wizuray/app/issues/new) and describe what happened.
- Have an idea? Open an issue too, or start a discussion.

Please never post private keys, passwords or personal data in an issue.
